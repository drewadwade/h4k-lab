# H4K Student Lab

## Download the lab

Download the current H4K lab package here:

**https://github.com/drewadwade/h4k-lab/releases/latest/download/H4K-Lab.zip**

Use that link rather than GitHub's **Code -> Download ZIP** option.

## Start the lab

1. Extract `H4K-Lab.zip`.
2. Open the extracted `H4K-Lab` folder.
3. Start the lab:
   - **Windows:** double-click `START-H4K.cmd`.
   - **Mac:** open **Terminal**, type `bash ` (including the space), drag `START-H4K.command` from Finder into the Terminal window, then press **Return**.
4. Follow the instructions shown by the launcher.

If Docker Desktop is not installed, the launcher will direct you to the official Docker installation instructions. Install and start Docker Desktop, then run START-H4K again.

The first launch may take longer while Docker downloads the lab environment.

## DVWA

When H4K is ready, DVWA opens at `http://localhost:8080` and a Kali Linux shell opens.

If DVWA asks to initialize its database, choose **Setup DVWA -> Create / Reset Database**.

Default login: `admin` / `password`

## Safety

Only use the security tools against the H4K lab or other systems your instructor has explicitly authorized.
